About the game

Escape:Malice is a two-player co-op horror puzzle game set in Edo-era Japan. While visiting the Miryoku-Ji Temple in Kamakura, the two protagonists fall into a strange hidden space beneath an old mansion, where resentful spirits are slowly waking in the dark.

The only way out is to explore, observe and solve puzzles together. The game was designed with real escape room designers, so the puzzles feel like a real escape room without the limits of a physical room. It cannot be played solo: every puzzle is built around communication and teamwork between the two players.

Mechanics

Click a mechanic to see it in action.

Footsteps change their sound depending on the surface the player is walking on. On every step, a line trace shoots straight down from the character and reads the Physical Material of the floor it hits. That surface is matched to a sound, and the player's machine asks the server to play it. The server then uses a Multicast RPC so every connected player hears the step at that character's location. Each step also reports a noise, so enemy AI can hear the player.

Every time the menu loads, the character picks a new spot in the scene so it never looks exactly the same twice. When the level starts, a toggle decides what happens. If it is on, the Blueprint picks a random point from a list of target points (soft references) and teleports the character to that point's location and rotation. If it is off, she teleports to one fixed point instead. Both paths check that the target is valid first, so a missing target is skipped instead of causing an error.

A safety net for graphics changes, like the confirm prompt in Windows display settings. When the player saves new settings, they are applied and a confirmation panel appears with a 10 second countdown. A looping timer ticks every second, lowers the countdown and updates the "Reverting To Previous Settings In" text. If it reaches 0, the previous settings come back automatically. Pressing Apply keeps the new settings, makes them the new fallback, stops the timer and hides the panel. Pressing Revert restores the previous settings straight away. The panel also works with a gamepad, where the stick switches the highlighted button and the interact input presses it.

A networked cutscene system that plays a full screen video for every connected player at the same time. The server authoritative GameState starts the cutscene with a Multicast RPC, and a Blueprint Function Library spawns the cutscene widget locally on each machine, with subtitles driven by a Data Asset. Players can hold a button to skip, and once at least 2 players have voted, the cutscene ends for everyone.

A hold-to-skip prompt that appears when the player moves the mouse and fades out after 5 seconds of inactivity. A radial fill shows the hold progress, and a live vote counter updates as other players request a skip.
